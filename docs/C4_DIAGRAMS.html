Data Flow Diagrams

Theme Switching Flow

sequenceDiagram participant User participant TimeMachine participant ThemeContext participant DesignSystems participant DOM participant Components User->>TimeMachine: Click era (e.g., "1970") TimeMachine->>ThemeContext: setTheme("1970") ThemeContext->>DesignSystems: getDesignSystemForTheme(theme) DesignSystems-->>ThemeContext: DesignSystemTokens ThemeContext->>DOM: Set CSS variables ThemeContext->>DOM: Set data-era="1970" DOM-->>Components: CSS variables updated Components->>Components: Re-render with new styles

Game Progress Flow

sequenceDiagram participant User participant Page participant MissionTracker participant GameContext participant LocalStorage User->>Page: Navigate to /about Page->>MissionTracker: Initialize tracking MissionTracker->>GameContext: isLevelCompleted("about-arrive")? GameContext-->>MissionTracker: false MissionTracker->>GameContext: completeLevel("about", "about-arrive") GameContext->>GameContext: Add XP, update progress GameContext->>LocalStorage: Persist progress User->>Page: Scroll 30% MissionTracker->>GameContext: completeLevel("about", "about-journey") GameContext->>GameContext: Add XP, check next level unlock

Arcade Game Flow

sequenceDiagram participant User participant GridArcade participant GameRegistry participant GameEngine participant RenderLoop User->>GridArcade: Select game "snake" GridArcade->>GameRegistry: getGameEntry("snake") GameRegistry-->>GridArcade: { createEngine } GridArcade->>GameEngine: createSnakeGame() GridArcade->>GameEngine: init(gridWidth, gridHeight) GridArcade->>RenderLoop: Start animation frame loop Every frame RenderLoop->>GameEngine: update(deltaTime) GameEngine->>GameEngine: Process game logic RenderLoop->>GameEngine: renderState() GameEngine-->>RenderLoop: { segments, food, score } RenderLoop->>GridArcade: Render to canvas end User->>GridArcade: Move cursor GridArcade->>GameEngine: onPointerMove({ x, y })

Sequence Diagrams

Full Page Load Sequence

sequenceDiagram participant Browser participant Vercel participant NextJS participant ThemeProvider participant GameProvider participant Page Browser->>Vercel: GET /about Vercel->>NextJS: Route to about/page.tsx NextJS->>NextJS: Server render RootLayout NextJS-->>Browser: HTML + JS bundles Browser->>Browser: Hydrate React Browser->>ThemeProvider: Initialize ThemeProvider->>ThemeProvider: Load theme from localStorage ThemeProvider->>Document: Apply CSS variables Browser->>GameProvider: Initialize GameProvider->>GameProvider: Load progress from localStorage Browser->>Page: Render About page Page->>Page: useMissionTracker() Page->>GameProvider: completeLevel("about", "about-arrive")

Contact Form Submission

sequenceDiagram participant User participant ContactForm participant API participant Arcjet participant Supabase participant MissionTracker User->>ContactForm: Fill form & submit ContactForm->>API: POST /api/contact API->>Arcjet: Check rate limit Arcjet-->>API: OK API->>Supabase: Insert message Supabase-->>API: Success API-->>ContactForm: 200 OK ContactForm->>MissionTracker: trackInteraction() MissionTracker->>GameContext: completeLevel("contact", "contact-send") ContactForm->>User: Show success message

Usage

Rendering PlantUML Diagrams

  1. Online: Paste code into PlantUML Web Server
  2. VS Code: Install "PlantUML" extension
  3. CLI: java -jar plantuml.jar C4_DIAGRAMS.md

Rendering Mermaid Diagrams

  1. GitHub: Renders automatically in markdown
  2. VS Code: Install "Markdown Preview Mermaid" extension
  3. Online: Mermaid Live Editor
