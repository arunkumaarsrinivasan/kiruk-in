# Kiruk hand fonts

Drop Calligraphr exports here:

- `KirukPrint.woff2` — architectural print (CAPS / labels / checklist)
- `KirukScript.woff2` — connected body script

Then set `KIRUK_HAND_READY = true` in `src/lib/sketch-ink/config.ts`
(or `NEXT_PUBLIC_USE_KIRUK_HAND=true`).

See `docs/SKETCH_INK_HAND.md` for the full capture + `calt` pipeline.
